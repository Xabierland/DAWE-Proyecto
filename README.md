## Iniciar el proyecto

### Instalar dependencias

```bash
npm install
```

### Entorno de Desarrollo

#### Iniciar el servidor

```bash
npm start
```

### Entorno de Produccion

#### Build

```bash
npm run build
```

#### Iniciar el servidor

```bash
serve -s build
```
